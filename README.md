## File structure

- `data/00-simulated_data` simulated sample, frame, and forecast.
- `data/01-raw_data` raw data as downloaded. Never edited by hand.
- `data/02-analysis_data` personas, model responses, and forecast outcomes (parquet).
- `models` saved model objects and fitted weights.
- `paper` Quarto source for the website.
- `scripts` simulation, download, persona, query, and forecast scripts, numbered in run order.
- `tests` test suites for the simulated data, the API responses, and the forecast.
- `other/sketches` sketches of the planned dataset and graphs.
- `other/llm_usage` logs of AI assistance.
- `other/literature` relevant papers.
- `docs` the rendered website, served by GitHub Pages.

## How to reproduce

1. Install [uv](https://docs.astral.sh/uv/) and clone the repo.
2. Run `uv sync` to recreate the environment from `uv.lock`.
3. Copy `.env.example` to `.env` and add an OpenRouter key.
4. Run the scripts in order, e.g. `uv run scripts/00-simulate_data.py`.
5. Run the tests with `uv run pytest`.
6. Run `uv run quarto render paper` (output goes to `docs/`).
