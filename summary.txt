PROJECT SUMMARY  (kept up to date by Claude; last updated 2026-10-30)
=====================================================================
Goal: forecast every 2026 US Senate race (35 contests) with a state-level
regression, as a transparent baseline next to the LLM "silicon sampling" forecast.
Senate seats are decided by statewide POPULAR vote (no Electoral College), so
vote share per state is the right target.

Method (scripts/05-regression.py)
 - Unit of analysis: one row per state per election cycle.
 - Features: weighted CES state profile (male, white, Black, Hispanic, college,
   mean age, % Republican, % Democrat) + ACS demographics (optional) + midterm flag.
 - Targets: three shares summing to 1: Democratic, Republican, Undecided/other.
 - Model: ridge regression on additive log-ratios (multi-class, stays on the
   simplex), penalty by leave-one-out CV.
 - Three training sets for the 2026 forecast: 2022 only, 2024 only, 2022+2024.
   Extra sets "midterms" and "all" appear when 2016-2020 data are present.
 - Tests: leave-one-state-out, predict other cycles, leave-one-cycle-out; MAE of
   each share vs. a mean-share baseline; winner accuracy; and, when
   data/01-raw_data/senate_results.csv exists, error vs. certified two-party share.
 - 2026 features carry forward the 2024 CES (and ACS).

Files

 scripts/05-regression.py                   features, models, metrics, 2026 forecast
 tests/test_regression.py                   unit + simulated end-to-end + real-data tests
 data/02-analysis_data/regression_*.parquet real-data outputs (CES features only so far)
 data/00-simulated_data/regression_*.parquet simulated-data outputs
 user_todo.txt / caveats.txt / summary.txt  tracking files (this one included)

Status
 - Pipeline runs end to end on simulated data (--source simulated) and on the real
   2022/2024 CES.
 - Real-data results so far (CES features only; targets are CES intent): Dem-share
   MAE about 4.6-5.7 pp vs 7-10 pp for a mean baseline; winner accuracy 82-94%.
   Not yet validated against certified results.
 - Waiting on: Census API key + ACS download, CES 2016-2020 download, certified
   results file (see user_todo.txt).

Run

 uv run scripts/05-regression.py --source simulated
